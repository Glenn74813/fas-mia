# ADR-002 — Token design
Status: Accepted. Decision: RS256 access JWT (10 min) with minimal claims (sub, sid, jti, iss, aud, exp); permissions resolved from the DB per request; opaque 256-bit refresh token in an HttpOnly/Secure/SameSite=Strict cookie scoped to /api/v1/auth, rotated on every use with reuse detection revoking the session family. Alternatives rejected: permissions in token (stale for up to the token lifetime after revocation); refresh token in localStorage (XSS exfiltration). Consequences: one extra indexed query per request; immediate revocation; CSRF protection required only on cookie-reading endpoints.
